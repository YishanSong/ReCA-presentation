Plan First. Communicate When Needed.

RESEARCH QUESTION

Do Bob and Alice need to re-plan and generate a message at every step?

PLAN → COMMUNICATE

Generate messages when essential.

Assess communication needs using dual memory.

PLAN → ACT → ACT

One high-level plan, multiple actions.

Guide consecutive low-level actions within a specified time frame.

Fewer LLM inferences.
Lower end-to-end latency.

Self-reflection monitors agent statuses and triggers re-planning when necessary.

先看(a)：基线每一步都先生成消息，再做高层规划，最后执行。再看(b)：ReCA先规划，只有需要通信时才生成消息；同一个高层计划也可以连续指导多个低层动作。Fig.9(c)示意四步中基线重复四次消息生成和规划；ReCA展示两次规划、一次消息生成和四步执行。这里第二次规划是图示消息发送分支返回后的新计划，并未明确由运行时反思触发；这不表示每次发送消息都必须重新规划。运行时监控与必要时重规划是§5.4中另行说明的机制。两行示例含不同的分支选择，不应声称一次计划永远覆盖全部任务或固定能获得某个加速比。

论文的约20%是预生成消息最终被使用的稀疏性观察，不是本动画中消息数的比例。多步执行可能累积误差，系统部署前要选择合适的多步长度，运行时通过self-reflection监测状态，必要时触发重规划并更新记忆。讲解最后过渡到后续低层执行：高层LLM开销降低后，低层路径规划成为更值得优化的部分。
