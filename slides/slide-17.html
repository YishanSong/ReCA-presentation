右侧表格采用论文 §7.2 的文字总结：12 个 agent 时，baseline 通常需要约一小时且成功率不足 70%；ReCA 保持约 90% 成功率并在 20 分钟内完成。这是跨系统的概括，并非每一条曲线在 12 个 agent 时都恰好为 90% 或 20 分钟。叙事重点是增加 agent 数量后的可扩展性，以及相同规模下 ReCA 与 baseline 的对照，不表示 ReCA 自身成功率随 agent 数量单调上升。
